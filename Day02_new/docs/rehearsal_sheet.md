# 60분 리허설 시트 (Day02_new 01~06)

## 먼저 읽을 것

- **2026-11-02 개정 안내:** 이 시트의 `기계 초`와 셀 번호는 2026-11-02 개정 이전의 `outputs/live/<노트북>.json` 기록에서 가져온 값입니다. 개정에서 노트북의 모든 코드 셀을 다시 썼고 일부 셀을 추가하거나 나눴으므로, `기계 초`와 셀 번호가 지금 노트북과 맞지 않을 수 있습니다. 시간표 행이 새로 생기거나 이름·범위가 바뀐 행은 `-`로 비웠고, 행이 그대로 남은 곳만 이전 값을 남겼습니다. `계획 분`은 개정된 노트북 `수업 시간표`와 맞췄습니다.
- **아직 아무도 리허설하지 않았습니다.** 아래 `계획 분`은 노트북 `수업 시간표`에서 옮긴 값이고, `실제 분`과 `메모`는 비어 있습니다. 이 시트의 어떤 숫자도 수업에서 시간이 맞는다는 증거가 아닙니다.
- **기계 초는 수업 시간이 아닙니다.** `기계 초`는 `outputs/live/<노트북>.json`에 기록된 셀 실행 시간(초)을 절 범위에 맞춰 더한 값으로, 코드가 도는 데 걸린 시간일 뿐입니다. 학생이 읽고, 예측하고, 값을 바꾸고, 질문하는 시간은 들어 있지 않습니다. 모델 응답 시간은 실행마다 다릅니다.
- 기계 초는 셀 번호(0부터)로 절에 매핑했습니다. 절 제목이 시간표 행과 1:1이 아닌 곳은 행을 묶었고(`5+6` 등) 묶인 행은 계획 분을 합쳐 적었습니다. 코드 셀이 없는 구간은 `-`입니다. 절별 기계 초의 합계는 기록의 총 초보다 작을 수 있습니다(총 초에는 커널 시작 등 셀 밖 시간이 들어 있을 수 있습니다. 이 원인은 확인하지 않았습니다).
- 04, 05, 06의 기계 초는 `outputs/live/<노트북>.json`의 가장 최근 값(05, 06은 마지막 재실행)이고, 01, 02, 03의 기계 초는 이전 실행의 값입니다. 03 선택 복사본도 다시 돌리지 않았습니다.
- 이 시트는 사람이 하는 점검입니다. 리허설을 마치기 전에는 완료로 표시하지 않습니다.

## 쓰는 법

1. 노트북 하나를 고릅니다(01부터 순서대로를 권합니다). 실제 키가 있는 환경에서 **수강생 속도**로 처음부터 끝까지 실행합니다. 결과를 미리 알고 빠르게 넘기지 않습니다. 예측하는 셀에서는 실제로 예측을 말하고 넘어갑니다.
2. 절이 끝날 때마다 시계를 보고 `실제 분`에 적습니다. 막힌 곳과 설명이 길어진 곳은 `메모`에 한 줄 남깁니다.
3. 노트북 하나가 끝나면 `실제 분` 합계를 `계획 분` 합계와 비교합니다. 초과한 절은 셀을 **자르거나**(선택 셀로 내림) 다른 절로 **옮깁니다**. 자르거나 옮긴 내용은 노트북 시간표와 절 제목의 분을 함께 고쳐 합이 60이 되게 합니다.
4. 6개 노트북 전체를 같은 방식으로 돌린 뒤, 합계가 수업 시간 안에 들어오는지 마지막 표에 적습니다.
5. 모델을 부르는 셀은 수강생 크레딧을 씁니다. 04~06의 Jev 관문 셀은 Decision API도 부르며 질문 문장과 근거가 공급자로 전송됩니다. 호출 규모는 각 노트북의 `호출 규모` 절을 따릅니다.

## 넘칠 수 있는 절 (추정이며 리허설이 아닙니다)

**이 절의 모든 숫자는 파일에서 센 값과 가정으로 계산한 추정입니다. 아무도 이 시간표로 수업을 해 보지 않았습니다.** 실제 분은 리허설에서만 얻습니다. `실제 분` 열은 비워 두었습니다.

계산 방법(가정 포함):

- 계획 분: 노트북 `수업 시간표`(위 표와 같은 값).
- 기계 초: `outputs/live/<노트북>.json`에서 해당 절의 셀 번호 범위에 든 셀의 `seconds`를 더한 값. 코드가 도는 시간만이며 모델 응답 시간은 실행마다 다릅니다.
- 코드 셀: 해당 범위의 `code` 셀 수(`<노트북>.ipynb`).
- 한글 자수: 해당 범위의 `markdown` 셀에서 한글 음절(가-힣) 개수. **가정: 수강생이 분당 400자를 읽는다.** 이 400자는 측정값이 아니라 가정입니다. 표·코드·출력은 읽는 시간에 넣지 않았습니다.
- 추정 A = 기계 초/60 + 한글 자수/400. 학생이 예측을 쓰고 출력을 읽고 질문하는 시간은 들어 있지 않아 **실제보다 작게 나옵니다.**
- 추정 B = 추정 A + 코드 셀 수 x 1분. **가정: 코드 셀 하나당 최소 1분(읽기, 예측, 출력 확인).** 이 1분도 측정값이 아닙니다(근거는 다른 읽기 점검의 인상이며 재 본 적이 없습니다).
- 플래그: `A초과` = 추정 A가 계획 분을 넘음. `B초과` = 추정 B가 계획 분을 넘음. 플래그가 없다고 시간이 맞는다는 뜻은 아닙니다.
