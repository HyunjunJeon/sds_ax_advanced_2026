# 할 일 보관함 쓰기

이 Skill은 MCP 서버 `tasks`의 도구 세 개를 쓴다: `add_task`, `list_tasks`, `complete_task`.
할 일 관리가 무엇인지 묻는 질문처럼 할 일을 실제로 바꾸거나 보지 않는 요청에는 도구를 쓰지 않고 바로 답한다.

1. **추가.** 사용자가 말한 행동을 그대로 `add_task`의 `title`에 넣는다. 다듬거나 줄이지 않는다.
   우선순위를 말하지 않았으면 `priority`를 생략한다(기본 normal). 사용자가 말하지 않은 우선순위를 지어내지 않는다.
   결과의 `created`가 false이면 같은 할 일이 이미 있었다는 뜻이다. 새로 만들었다고 말하지 않는다.
2. **보기.** `list_tasks`를 부른다. 끝낸 것까지 보고 싶다고 하면 `status`를 `all`로, 끝낸 것만이면 `done`으로 한다.
3. **끝내기.** `complete_task`에는 `task_id`가 필요하다. ID를 모르면 먼저 `list_tasks`로 찾는다.
   제목이 맞는 할 일이 둘 이상이면 어느 것인지 사용자에게 묻는다. 짐작해서 끝내지 않는다.
4. **오류.** 결과가 `success: false`이면 `error` 값에 따라 행동한다.
   - `title_too_short`: 무엇을 할지 사용자에게 다시 묻는다.
   - `task_not_found`: `list_tasks`로 ID를 다시 확인한다. 그래도 없으면 없다고 알린다.
   - `permission_denied`: 같은 호출을 되풀이하지 않는다. 어떤 도구가 거절되었는지 사용자에게 알린다.
   - `temporarily_unavailable`: 같은 호출을 같은 인자로 한 번만 다시 보낸다. 또 실패하면 멈추고 알린다.
   서버가 거절한 작업을 끝냈다고 말하지 않는다.
5. **보고.** 바뀐 할 일의 `task_id`와 상태를 답에 남긴다.
