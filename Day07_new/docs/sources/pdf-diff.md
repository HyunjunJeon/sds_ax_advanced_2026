# 강의 PDF와 v0.32.0 대조

대상은 `Day7_vLLM_기초와_추론_속도_최적화.pdf`(텍스트 추출본)와 `Day07/` 문서·스크립트다. 기준은 vLLM v0.32.0 소스(commit 5df63a7)와 그 안의 `docs/`, 그리고 GLM-5.3-Flash 공식 레시피(2026-10-19 갱신)다. 소스에는 변경 이력과 태그가 없어서 "어느 버전부터"라는 주장은 소스만으로 확인하지 못한다. 그런 주장은 `미확인`으로 두었다.

## 판정 기준

| 판정 | 뜻 |
|---|---|
| 일치 | v0.32.0 코드·문서와 같다 |
| 표현 주의 | 틀리지는 않지만 수강생이 오해할 수 있거나, 설명용 예시라고 밝힌 값이 실제와 다르다 |
| 버전 차이 | 이전 버전에서는 맞았거나 다른 버전에서만 맞다 |
| 오류 | 사실과 다르다 |
| 미확인 | 이 소스만으로는 확인할 수 없다 |

PDF가 "설명용 예시"·"교육용"·"개념도"라고 밝힌 값은 `오류`로 두지 않았다. 이번 대조에서 PDF 쪽 `오류` 판정은 없다.

경로는 v0.32.0 소스 루트 기준이다(`vllm/...`, `docs/...`). `Day07/...`는 이 저장소 경로다.
