# Day07_new 강사용 진행 경로

이 문서는 강사가 노트북 01~06(02c와 04b 포함)을 수업에서 어떻게 지나갈지 정한 **제안**입니다. 노트북은 그대로 두고, 이 문서가 "수업에서 말하는 것"과 "자습으로 넘기는 것"을 가릅니다. 이 경로를 타이머로 재거나 리허설한 사람은 없습니다. 분 배정은 노트북의 `## 수업 시간표`를 그대로 옮겼고, 말할 분량은 아래 가정으로만 어림했습니다.

**소리 내어 말할 글은 `docs/script/`에 있습니다.** `docs/script/01-02.md`, `docs/script/03-04.md`, `docs/script/05-06.md`에 절마다 `> 보일 셀` 줄과 말할 글을 적었고, 절 제목의 분은 노트북의 시간표와 같습니다. **두 문서가 어긋나면 셀 번호, 분, 예측 표시, 말할 내용 어느 것이든 대본이 우선합니다.** 대본은 이 표보다 넓게 말합니다. 표의 `자습으로 넘길 내용`에 적힌 일부 셀(예: 01의 셀 12, 04b의 셀 2와 3)도 대본에서는 보여 줍니다. 이 표는 시간이 모자랄 때 무엇을 줄일지 고르는 기준으로 읽고, 줄일 때는 대본에서 보여 주는 셀 가운데 표가 자습으로 돌린 것부터 자습으로 넘깁니다. 표의 교실 셀은 모두 대본의 `> 보일 셀` 줄(03-04는 `> 보여 줄 셀` 줄)이 가리킵니다. 이 경로와 그 글은 아직 리허설하지 않았습니다. 수업 전에 강사가 한 절 이상을 소리 내어 읽으며 시간을 한 번 재서, 분당 300자 가정과 절 분 배정이 맞는지 확인하세요. 맞지 않으면 이 문서의 분 배정이 아니라 말하는 양과 자습으로 넘기는 몫을 조정합니다.

이론 시간은 처음 계획한 240분(01, 02a, 02b, 03, 04)에서 330분으로 늘었습니다. 02c(45분)와 04b(45분)를 더한 결과입니다. 저자가 내용이 240분 목표를 넘어 자라도록 허용했습니다. 시간표를 맞추려고 내용을 줄인 것이 아니라 내용을 먼저 정하고 시간을 다시 센 것이므로, 아래 예산 비율은 이전보다 낮고 자습으로 넘기는 몫이 큽니다.

진행 방식에 대한 제안은 세 가지입니다.

- 모든 노트북은 출력이 저장된 채로 열립니다. 수업에서는 저장된 출력을 보여 주고, 아래 표의 셀만 짚으면서 말합니다. 수업 전에 각 노트북을 처음부터 끝까지 한 번 Run All 해 둡니다. 맨 앞 셀만 실행하면 값을 바꾸는 해보기 셀과 교실 셀이 자습으로 넘긴 셀의 정의(예: 01의 셀 39, 03의 셀 18)를 쓰고 있어서 NameError가 납니다.
- 각 절에서 말할 것은 표의 `말할 핵심` 두세 가지입니다. 노트북 본문을 그 순서로 읽어 주는 것이 아닙니다.
- `먼저 예측하세요.`가 붙은 절은 학생이 종이에 적은 뒤에 셀을 보여 줍니다. 예측 시간은 이 절에 배정된 분 안에서 쓰고, 부족하면 예측을 한 문장으로 줄입니다.

`교실에서 실행할 셀`의 번호는 저장된 노트북의 0부터 시작하는 셀 번호이고, 모두 코드 셀입니다. `교실에서 실행할 셀`은 Run All 뒤에 다시 실행하거나 저장 출력을 짚을 셀이고, 이 셀들만 처음부터 돌리는 순서가 아닙니다. `예측` 표시는 바로 앞 마크다운 셀에 `먼저 예측하세요.`가 있다는 뜻이고, 해보기 지시 글의 "먼저 적고"도 포함합니다.
