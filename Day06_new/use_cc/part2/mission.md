§2a 표의 여섯 칸에 **줄 번호와 근거 수준**을 적는다. 칸마다 한 줄이면 충분하다.

- 조교는 줄을 함께 열어 주지만 칸을 대신 채우지 않는다. "이 줄은 어느 책임인가요?"를 내가 답한다.
- 거대한 부분을 통째로 읽지 않는다. 함수 이름으로 찾아 들어간다(`grep -n "def " vendor/mini-coding-agent/mini_coding_agent.py`).

## M2-3. `[내 것 만들기]` 내 하네스의 지도를 센다 (6분)

내가 평소 Claude Code를 여는 업무 폴더 하나를 고른다. 업무 폴더가 없으면 홈 폴더(`~`)나 개인 프로젝트 폴더도 된다.

`[따라하기]` 조교 세션에서:

```text
!uv run python tools/harness_inventory.py ~/work/내-프로젝트
```

- 출력에는 **개수만** 나온다. 파일 경로, Skill 이름, MCP 서버 이름, 설정 값은 나오지 않는다. 그래서 이 세션에서 쳐도 된다.
- 이름까지 보고 싶으면 **Claude Code 밖의 일반 터미널**에서 `--reveal`을 붙인다. Claude Code 안에서 치면 도구가 거절한다(이름이 모델로 전송되기 때문).

§2b 표에 옮겨 적고 두 줄을 더 쓴다.

- **비어 있는 칸**: 여섯 책임 중 "없음"이 나온 칸
- **있는 줄 몰랐던 것**: 예를 들어 Skill 수, 다른 프로그램이 넣어 둔 hook, 상위 폴더의 CLAUDE.md

**관찰할 것.**
- 표의 "지침" 행: 시작 폴더가 아닌 곳(위 폴더, 사용자 전역)에서 오는 지침이 있는가
- "검증" 행: 지침 파일에 검사 명령이 몇 줄인가. 실행 뒤 hook이 있는가
