# 계획 양식 (Part 5)

내 작업에 맞게 칸을 고쳐 쓰는 출발점이다. 칸의 근거는 `part5/concept.md` 3절에 있다. 쓰지 않을 칸은 지우고, 왜 지웠는지 §5c에 한 줄 적는다.

## 머리

| 칸 | 쓰는 것 |
|---|---|
| 의도 | 사람이 쓴 문단 그대로(무엇을, 왜, 완료 기준, 범위 밖) |
| 조사 결과 | 계획 전에 확인한 지금 상태. 실행한 명령과 결과 |
| 범위 밖 | 이번에 하지 않는 것 |
| 위험 | 틀리면 크게 되돌려야 하는 결정 |
| 사람 확인 지점 | 승인 없이 넘어가면 안 되는 곳 |
| 실행 구조 | 한 세션에서 차례로 / 작업마다 새 하위 에이전트 / 단계마다 사람 배턴 / 정해진 게이트에서만 멈춤 |

## 작업마다

| 칸 | 쓰는 것 |
|---|---|
| 작업 ID | T1, T2 … |
| 연결 요구사항 | 이 작업이 채우는 완료 기준(예: R4) |
| 바꿀 파일 | 정확한 경로 |
| 먼저 실패할 검사 | 검사 이름 또는 새로 쓸 검사 |
| 통과의 뜻 | 실행할 명령과, 통과를 뜻하는 출력 |
| 멈추고 물을 조건 | 예: 검사 파일을 바꿔야 할 것 같을 때, 같은 원인으로 세 번 실패할 때 |
| 실행 주체 | 이 세션 / 새 하위 에이전트 / 사람 |
